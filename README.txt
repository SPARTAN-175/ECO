ECO — PWA 120 niveles
=====================

1. Sube TODO el contenido de esta carpeta a la raíz de tu hosting.
2. Abre index.html desde el dominio HTTPS.
3. La primera visita descarga los archivos esenciales y después el juego puede funcionar sin conexión.
4. En Android/Chrome usa "Instalar aplicación" / "Agregar a pantalla de inicio".

Estructura:
- index.html          juego y UI
- levels.json         120 niveles
- manifest.webmanifest configuración PWA
- sw.js               caché/offline
- assets/             iconos
